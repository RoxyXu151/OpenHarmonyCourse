# OpenHarmonyCourse

**简体中文** | [English](README.en.md)

鸿蒙开发基础学习资料，包含 HelloHomo 示例工程及教程笔记、代码归档和图片素材，覆盖 ArkUI 界面、组件与状态管理练习。

## 环境要求

DevEco Studio；HelloHomo 的构建配置声明 HarmonyOS 5.0.3 / API 15 兼容 SDK。

## 获取仓库

```bash
git clone https://github.com/RoxyXu151/OpenHarmonyCourse.git
cd OpenHarmonyCourse
```

私有仓库需要先通过 GitHub 认证。以下相对路径与操作均以本仓库为起点。

## 安装与启动

本项目按下方说明使用对应编辑器或阅读工具；当前没有统一的命令行启动步骤。

## 配置与准备

在 DevEco Studio 中打开 HelloHomo/，而不是仓库根目录。完成 SDK 和 OHPM 同步；真机运行时设置自己的签名。仓库名不意味着示例适配所有 OpenHarmony 发行版。

## 使用方法与产物

先学习教程中的界面与布局内容，再运行 HelloHomo，逐步修改组件与状态。教程代码 ZIP 是独立阶段资料，需解压到单独目录后按各自配置打开。
