# OpenHarmonyCourse

[简体中文](README.md) | **English**

HarmonyOS development learning materials with the HelloHomo example project, course notes, code archives, and image resources, covering ArkUI screens, components, and state-management exercises.

## Requirements

DevEco Studio. HelloHomo declares a HarmonyOS 5.0.3 / API 15 compatible SDK in its build configuration.

## Get the repository

```bash
git clone https://github.com/RoxyXu151/OpenHarmonyCourse.git
cd OpenHarmonyCourse
```

Private repositories require GitHub authentication. Relative paths and steps below start from this repository.

## Setup and entry point

Use the editor or reading tools described below; there is no shared command-line launch sequence.

## Configuration and preparation

Open HelloHomo/ in DevEco Studio rather than the repository root. Sync SDK and OHPM dependencies and configure your own signature for device runs. The repository name does not imply compatibility with every OpenHarmony distribution.

## Usage and outputs

Study the UI and layout materials, run HelloHomo, and gradually modify components and state. Course ZIP archives represent separate stages; extract them to separate folders and use their own project settings.

## Verification and troubleshooting

Verify build, navigation, and exercise interactions on a compatible device or emulator. Images, courseware, and third-party materials retain their attribution. There is no shared command-line test entry.

## Maintenance and contributions

Keep both READMEs in sync when functionality or usage changes. Report reproducible steps, environment versions, and sanitized logs. Describe the verification actually performed with each change.
